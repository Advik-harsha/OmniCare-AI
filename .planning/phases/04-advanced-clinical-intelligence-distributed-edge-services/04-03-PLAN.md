# Plan 04-03: Regional Counselor, DICOM Web-PACS & Federated DP-SGD Engine

**Goal:** Implement on-device multilingual patient counseling in 8 Indian languages, DICOM 3.0 Web-PACS micro-server with Hounsfield Unit windowing presets, and Differential Privacy (DP-SGD ε=1.2, δ=10⁻⁵) federated learning engine.

## User Story
**As a** clinician serving linguistically diverse populations and managing edge radiological scans,  
**I want to** synthesize patient discharge advice in regional Indian languages, query on-device DICOM studies with medical window presets, and contribute to privacy-preserving federated model improvements,  
**so that** patients receive clear instructions in their mother tongue, radiological imaging is accessible offline, and zero biometric data leaves the device.

<task type="auto">
  <name>Implement Differential Privacy (DP-SGD) Federated Learning Engine</name>
  <files>
    backend/engine/federated_privacy.py,
    backend/main.py
  </files>
  <action>
    1. Implement `backend/engine/federated_privacy.py` using dual-import pattern:
       - Differentially Private Stochastic Gradient Descent (DP-SGD) implementation:
         * Per-sample gradient clipping with L2 norm threshold C = 1.0.
         * Calibrated Gaussian noise addition: sigma = (C * sqrt(2 * ln(1.25 / delta))) / epsilon.
         * Privacy parameters enforced: epsilon = 1.2, delta = 1e-5 (Rényi Differential Privacy / Moments Accountant verification).
       - Cumulative privacy budget tracker preventing model extraction or gradient reconstruction attacks.
       - Model weight delta export with SHA-256 Merkle root verification for peer edge federation.
    2. Mount REST endpoints in `backend/main.py`:
       - `GET /api/federated/privacy/budget` (returns current spent and remaining privacy budget epsilon, delta, and status).
       - `POST /api/federated/privacy/sanitize_delta` (accepts raw model weights/gradients, clips gradients, injects calibrated noise, and returns sanitized DP delta).
  </action>
  <verify>
    <automated>python -c "from backend.engine.federated_privacy import sanitize_weight_delta, get_privacy_budget; res = sanitize_weight_delta([0.45, -0.82, 0.12, 1.55]); bg = get_privacy_budget(); assert len(res['sanitized_delta']) == 4; assert bg['epsilon'] == 1.2; assert bg['dp_guarantee_active'] is True; print('DP-SGD OK')"</automated>
  </verify>
  <done>Differential Privacy engine enforces DP-SGD bounds (ε=1.2, δ=10⁻⁵) on edge federated updates.</done>
