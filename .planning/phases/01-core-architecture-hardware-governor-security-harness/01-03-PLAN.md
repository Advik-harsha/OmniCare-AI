# Plan 01-03: Ralph Autonomous Loop Harness & CodeRabbit Review Integration

**Goal:** Establish the autonomous development and code review harness integrating Geoffrey Huntley's Ralph pattern (`prd.json` + `ralph.ps1`/`ralph.bat`) and CodeRabbit review configuration (`.coderabbit.yaml`).

## User Story
**As a** core developer building on-device clinical software,  
**I want an** autonomous iterative task loop with fresh context execution and automated AI review gates,  
**so that** development moves forward with zero regressions, strict privacy compliance, and verified code health.
