# Plan 01-01: Backend Core Infrastructure, NPU Telemetry & HP Smart Sense Governor

**Goal:** Establish the foundational FastAPI backend service, Snapdragon X Elite NPU hardware profiling engine, HP Smart Sense thermal/power governor, and 1-click execution scripts.

## User Story
**As a** clinical diagnostic workstation user or challenge judge,  
**I want to** launch OmniCare AI locally with a single click and access live Hexagon NPU telemetry and HP Smart Sense power profiles,  
**so that** I experience sub-15ms edge inference with optimal battery endurance and acoustic quietness.
